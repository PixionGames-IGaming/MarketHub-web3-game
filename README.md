# ChainPlayX — Web3 Game Hub

ChainPlayX is a Web3 game hub built on the original ChainPlayX Hub project structure, redesigned around a Nexora-inspired dark arcade UI with chunky 3D controls, game modes, player progression, inventory, rankings, quests, and on-chain-style rewards.

## Run

```bash
npm install
cd client
npm install
cd ..
npm run build
npm start
```

Open `http://127.0.0.1:9030/`.

## Included

- React 18 + React Router
- Existing ChainPlayX Hub project structure and routes
- Web3/game-oriented home experience
- Nexora-inspired dark/glow visual language
- Raised 3D game buttons and cards with press states
- Responsive desktop/tablet/mobile layouts
- Existing wallet/session/API scaffolding retained
